# BiliDanmuCheck

## 模块简介
这是一个基于 Xposed/LSPosed 框架的哔哩哔哩（Bilibili）客户端辅助模块，主要提供纯净的观看体验以及实用的弹幕溯源功能。

## 主要功能

* **去除广告**
  * 移除 Bilibili 客户端内的所有广告内容。
  * 兼容性提示：本功能截至 Bilibili 客户端版本 9.11.0 测试有效。由于官方客户端会不断更新，高于此版本的应用可能会出现部分去广告规则失效的情况。

* **查看弹幕发送者**
  * 触发方式：在视频播放过程中，点击并复制您想查询的弹幕，即可触发查看该弹幕发送者的信息。
  * 注意事项：受限于客户端机制与服务端接口的变动，此查询功能存在一定的失败概率，请视作辅助功能使用。

## 安装与使用方法

1. 确保您的设备已经安装并正常运行 Xposed、LSPosed 或其他兼容的 Hook 框架。
2. 下载并安装本模块的 APK 文件。
3. 打开您的框架管理器（如 LSPosed），在模块列表中启用本模块，并勾选作用域：哔哩哔哩。
4. 在系统设置或应用详情中强行停止 Bilibili 客户端的运行。
5. 重新启动 Bilibili 客户端，模块功能即可生效。

## 兼容性说明
* 目标应用：哔哩哔哩 (tv.danmaku.bili)
* 测试环境：Bilibili v9.11.0
* 框架依赖：LSPosed / Xposed
